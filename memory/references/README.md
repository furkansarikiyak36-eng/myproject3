# References

Our own text analyses of reference games, videos and images, so every assistant can
use them without the files. Never store other people's images, models, textures or
long quotes here; describe in our own words what is seen and what we take from it.

One file per subject: `<game>_<subject>.md`, for example `sotf_log_wall_corner.md`.

```markdown
# Sons of the Forest · log wall corner
Source: in-game, building a cabin corner (or a link to the public video, with time)
## Seen
- Plain description of the structure and how the player makes it.
## Measures and rules
- Angles, distances, order of steps, what snaps to what.
## In our project
- Matching profile or module (for example `log.parallel_stack`), and the difference.
## Status
- exists / missing / different
```
